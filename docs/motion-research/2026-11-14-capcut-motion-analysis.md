## 2. 공통 패턴 분석

1. **컷 박자 (리듬 구조)**
   - **설명·튜토리얼형(v01~v06)**: 초반 **2~2.7초 훅(Hook)** 후 본편은 **2.0~3.6초** 호흡으로 전개되며, 비포/애프터 비교나 강조 포인트만 **1.0초**로 짧게 끊습니다.
   - **인스타 릴스 템플릿형(v07, v08, v10)**: 초반 **4~7초 빌드업**으로 시선을 묶은 뒤, 비트 드롭 이후 **0.33~0.75초 초고속 교차**로 몰아칩니다(감성 롱테이크 v09만 예외).
   - AutoReels의 컷당 2~3초 구조에는 **2~3초 컷 안에 0.3~0.5초짜리 진입 모션/중간 펄스**를 넣어 지루함을 깨는 방식이 가장 적합합니다.
2. **자주 쓰는 전환 및 화면 효과**
   - **단순 컷/슬라이드 대신 '광학·공간감' 효과**: 어안 왜곡 줌(v02), 카메라 글로우/라이트 릭 이중노출(v02, v10), 보케 블러(v03), 비네트와 시네마틱 레터박스(v06), 포토부스/미니프레임 액자(v03), 세로 반쪽 엇갈림 분할(v08).
   - **전경/배경 분리 느낌**: 누끼를 못 따더라도 흐린 배경 위에 선명한 중앙 프레임(v01)이나 레터박스·비네트로 시선을 중앙에 가두는 구도(v06)를 매우 선호합니다.
3. **텍스트 모션 경향**
   - **짧고 굵은 리듬 자막**: 3~5음절씩 중앙·하단에 굵은 고딕+외곽선(v02, v03) 또는 흰 알약/사각 박스(v06)로 한눈에 읽히게 배치합니다.
   - **UI 모방형 그래픽 텍스트**: 검색창 타이핑 바(v06), `Before / After` 상태 배지(v06), `1단계` 알약 태그(v01), 측면 엔딩 크레딧 롤(v07)처럼 **플랫폼·영화 UI를 차용한 텍스트**가 정보 전달력이 높습니다.

## 3. AutoReels 신규 모션 프리셋 8종 제안

*(기존 25개 프리셋과 겹치지 않으며, 브라우저 `<canvas>`에서 사진 1장·컷 길이 2~3초 기준으로 구현 가능한 프리셋입니다.)*

### 1) 어안 빨려들기 줌 (워프 풀인)
- **근거**: v02 (`00:03.333`~`00:03.667` "줌인")
- **시간표** (컷 시작 전환 0.45초 + 정착 2.0초):
  - `0.00~0.20초`: 사진 중앙이 볼록하게 휘어지며 스케일 `1.65x → 1.15x`로 급격히 당겨 들어옴(수직 방향 모션블러 강함).
  - `0.20~0.45초`: 배럴 곡률 왜곡과 블러가 `100% → 0%`로 풀리며 스케일 `1.15x → 1.00x` 안착.
  - `0.45~2.50초`: `1.00x → 1.04x` 미세 켄번즈 전진.
- **이징**: `easeOutExpo` (진입부) / `linear` (유지부)
- **Canvas 그리기 방법**:
  - 컷 사진을 오프스크린 캔버스에 먼저 그린 뒤, 세로 방향으로 24~32개 수평 스트립(또는 격자)으로 `drawImage` 분할 렌더링. 각 스트립의 `y` 위치에 따라 `sin(normalizedY * Math.PI)` 비율로 가로 폭과 `dy`를 비선형 확대해 **볼록/오목 어안 곡면**을 근사하고, 이전 3프레임의 반투명(`globalAlpha = 0.25`) 잔상을 세로 오프셋(`±12px`)으로 겹쳐 수직 모션블러 구현.
- **어울리는 업종**: 자동차 영업(주행감/외관 임팩트), 헬스, 쇼핑몰(신상 오픈).

### 2) 카메라 글로우 빛번짐 전환
- **근거**: v02 (`00:10.667`~`00:11.333` "카메라 글로우"), v10 (`00:05.000` 라이트 릭 디졸브)
- **시간표** (전환 길이 0.60초):
  - `0.00~0.25초`: 화면 하단·모서리에서 앰버/오렌지빛 방사형 글로우와 수직 빛줄기가 차오르며 노출(밝기) 상승.
  - `0.25~0.40초`: 이전 사진과 새 사진이 반투명 이중 노출(`alpha` 교차)로 겹친 상태에서 하이라이트 글로우 피크.
  - `0.40~0.60초`: 빛 번짐과 블룸이 가라앉으며 선명한 새 사진으로 정착.
- **이징**: `easeInOutSine`
- **Canvas 그리기 방법**:
  - 사진 레이어 위에 `ctx.globalCompositeOperation = 'screen'`(또는 `'lighter'`) 모드로 다중 `createRadialGradient`(중심 `#fff3d6` → `#ff8c32` → 투명)와 수직 선형 빛줄기 그라데이션, 작은 반투명 원형 보케 입자 6~8개를 그려 넣고 `ctx.filter = 'brightness(...)'`를 `1.0 → 1.45 → 1.0`으로 보간.
- **어울리는 업종**: 카페, 미용(헤어/메이크업 화보), 음식점, 쇼핑몰.

### 3) 보케 스포트라이트 포커스
- **근거**: v03 (`00:06.667`~`00:08.667` "갤럭시 블러")
- **시간표** (컷 내부 연출 총 0.80초 포커스인 + 유지):
  - `0.00~0.35초`: 화면 전체가 강한 블러(`24px`) + 은은한 파스텔/보랏빛 틴트 상태로 등장.
  - `0.35~0.80초`: 중앙 타원/원형 스포트라이트 마스크 반경이 `0% → 42%`로 부드럽게 열리며 중앙 피사체는 선명하게, 외곽 배경은 보케 블러(`14px`)와 반짝이는 빛망울 원형이 남는 아웃포커싱 완성.
- **이징**: `easeOutCubic`
- **Canvas 그리기 방법**:
  - 배경 레이어는 `ctx.filter = 'blur(14px)'`로 그린 뒤 반투명 파스텔 보케 원형(`globalCompositeOperation = 'screen'`) 여러 개를 배치. 그 위에 `ctx.save()` → 선명한 원본 사진을 그리되 부드러운 페더 효과를 위해 오프스크린 마스크 캔버스(`createRadialGradient` 불투명→투명 알파 마스크 + `globalCompositeOperation = 'destination-in'`)를 합성해 중앙부만 또렷하게 얹음.
- **어울리는 업종**: 카페(디저트/라떼), 음식점(메인 요리), 병원/피부과, 미용(네일/속눈썹).

### 4) 포토부스 인화 슬롯
- **근거**: v03 (`00:10.333`~`00:12.000` "러버부스")
- **시간표** (출력 연출 0.90초 + 정지 감상 1.60초):
  - `0.00~0.15초`: 상단 밝은 미니멀 배경(연회색/아이보리) 위에 입체 그림자가 진 흰색 프린터 배출 슬롯 바 등장.
  - `0.15~0.75초`: 두꺼운 흰색 인화지 프레임(하단 여백에 업종 날짜/한 줄 카피 각인)에 담긴 사진이 슬롯 아래로 "드륵-스륵" 2단 스텝감 있게 내려옴(`translateY: -100% → 0%`).
  - `0.75~0.90초`: 슬롯 하단에서 미세하게 1.5° 기울어지며 종이 흔들림 후 고정.
- **이징**: `easeOutBack` (2단 출력 구간은 2회 감속 커브 결합)
- **Canvas 그리기 방법**:
  - 밝은 스튜디오 톤 배경을 채운 뒤, 상단 슬롯 라인 아래 영역에만 `ctx.beginPath(); ctx.rect(x, slotY, w, h); ctx.clip()` 클리핑 마스크를 적용. 그 내부에서 흰 폴라로이드/네컷 스트립 카드(그림자 `shadowBlur` 포함)와 사진을 `translateY`·미세 `rotate` 변환해 그린 다음, 클립 해제 후 최상단에 슬롯 입구 립(lip) 그래픽을 덮어 사진이 기계 안에서 나오는 듯한 깊이감 구현.
- **어울리는 업종**: 카페, 미용, 쇼핑몰(데일리룩), 음식점(데이트 맛집).

### 5) 비트 에코 잔상 펄스
- **근거**: v06 (`00:07.333`~`00:07.667`, `00:08.667` "비트 에코")
- **시간표** (컷 내 비트 포인트 0.50초, 컷당 1~2회 트리거 가능):
  - `0.00~0.12초`: 컷 본체는 `1.02x` 미세 펀치.
  - `0.12~0.42초`: 2~3개의 반투명 복사 레이어가 `1.00x → 1.32x`로 시간차를 두고 바깥쪽으로 퍼져 나가며 잔상(`alpha: 0.45 → 0.0`)으로 소멸.
  - `0.42~0.50초`: 가장자리 미세 에지 글로우 후 깨끗한 정지 상태 복귀.
- **이징**: `easeOutQuart`
- **Canvas 그리기 방법**:
  - 원본 사진을 `scale = 1.0`으로 중앙에 고정 렌더링한 뒤, `for (let i = 1; i <= 3; i++)` 루프로 지연 오프셋(`delay = i * 0.05`)을 둔 진행도 `p`를 계산해 `ctx.globalAlpha = (1 - p) * 0.4`, `ctx.filter = 'blur(' + (p * 6) + 'px)'`, `scale = 1 + p * 0.3` 상태로 `drawImage` 반복 호출.
- **어울리는 업종**: 헬스(PT/바디프로필), 자동차 영업, 쇼핑몰(스트릿/세일 홍보).

### 6) 시네마틱 비네트 & 레터박스 스코프
- **근거**: v06 (`00:23.667`~`00:25.667` "영화 화면", `00:28.000`~`00:29.667` "비네트")
- **시간표** (0.55초 무드 전환 + 2.0초 유지):
  - `0.00~0.25초`: 선명하고 밝은 원본 사진이 먼저 노출됨(Before 감각).
  - `0.25~0.55초`: 상하 2.35:1 검은 레터박스 바가 위·아래에서 부드럽게 좁혀 들어오며(`height: 0% → 13%`), 동시에 사방 모서리에 딥 다크 브라운 비네팅이 서서히 조여져 중앙 피사체 몰입감 형성(After).
  - `0.55~2.50초`: 레터박스 하단 여백에 영문/한글 서브 카피 고정, 사진은 미세 슬로 줌(`1.00x → 1.03x`).
- **이징**: `easeInOutCubic`
- **Canvas 그리기 방법**:
  - 사진 렌더링 후 `createRadialGradient(cx, cy, rInner, cx, cy, rOuter)`로 중앙 투명(`rgba(0,0,0,0)`) → 외곽 짙은 웜블랙(`rgba(15,12,10,0.68)`) 비네트 오버레이. 이어서 상단(`y=0`)과 하단(`y=H-barH`)에 불투명 검은 사각형(`barH` 보간)을 그리고, 하단 레터박스 중앙에 자막 렌더링.
- **어울리는 업종**: 인테리어(공간 포트폴리오), 자동차 영업(고급 세단/SUV), 부동산, 파인다이닝 음식점.

### 7) 세로 반쪽 엇갈림 맞물림 (Vertical Stagger Split)
- **근거**: v08 (`00:20.667`, `00:21.333` 세로 2분할 어긋남 모션)
- **시간표** (전환 길이 0.50초):
  - `0.00~0.35초`: 화면이 정확히 좌/우 2개의 세로 컬럼(`0~W/2`, `W/2~W`)으로 나뉜 상태에서, 좌측 절반은 위(`-28%`)에서 아래로, 우측 절반은 아래(`+28%`)에서 위로 반대 방향으로 빠르게 미끄러지며 들어옴(이동 중 얇은 검은 여백과 수직 모션블러).
  - `0.35~0.50초`: 두 절반이 중앙선에서 `±2%` 미세 오버슈트 후 `0px` 오차로 딱 맞물리며 한 장의 온전한 사진 완성.
- **이징**: `easeOutBack` (과도하지 않은 `overshoot = 1.1`)
- **Canvas 그리기 방법**:
  - 좌측 반쪽: `ctx.save()` → `rect(0, 0, W/2, H)` 클리핑 후 `drawImage(img, 0, offsetY_L, W, H)` (단, 상하 소스/렌더 영역 클리핑) 또는 `drawImage(img, 0, 0, imgW/2, imgH, 0, offsetY_L, W/2, H)`. 우측 반쪽: `rect(W/2, 0, W/2, H)` 클리핑 후 `offsetY_R = -offsetY_L`로 반대 방향 이동. 합쳐지는 순간(`progress > 0.85`) 가운데 경계선에 얇은 하이라이트 플래시 선 1회 소거.
- **어울리는 업종**: 미용(시술 전후/좌우 스타일링), 인테리어(공간 변화), 부동산, 쇼핑몰(상하의 코디).

### 8) 사이드 그라데이션 크레딧 롤
- **근거**: v07 (`00:08.333`~`00:30.667` 좌측 사진 + 우측 페이드 크레딧 스크롤)
- **시간표** (2.5~3.0초 엔딩/요약 컷 전용):
  - `0.00~0.35초`: 우측 약 35% 영역에 부드러운 검은 그라데이션 페더가 페이드인되고, 사진 중심점이 살짝 좌측(`x: -8%`)으로 이동해 좌측 시야 확보.
  - `0.35~2.80초`: 우측 어두운 그라데이션 영역 위로 매장 정보(영업시간·위치·대표 메뉴·전화번호·시그니처 문구)가 아래에서 위로 일정 속도로 부드럽게 롤링 스크롤.
- **이징**: 그라데이션·패닝은 `easeOutCubic`, 크레딧 롤링은 `linear`
- **Canvas 그리기 방법**:
  - 사진을 좌측으로 살짝 패닝해 그린 뒤, 전체 화면 위에 수평 선형 그라데이션(`createLinearGradient(W*0.45, 0, W*0.78, 0)`으로 `rgba(0,0,0,0)` → `rgba(10,10,12,0.92)`) 사각형을 덮어 사진과 텍스트 영역의 경계를 매끄럽게 녹임. 이후 우측 영역(`x = W*0.65 ~ W*0.95`)에 세로 클리핑 후 여러 줄 텍스트의 `y` 좌표를 매 프레임 일정 픽셀(`-speed * dt`)씩 위로 올려 렌더링.
- **어울리는 업종**: 음식점, 카페, 학원(커리큘럼/강사진), 병원(진료시간/진료과목), 부동산, 인테리어(마무리 요약 컷).

## 4. 자영업 사장님 홍보 영상에 쓰면 안 되거나 어색한 유행 요소

1. **180도 화면 뒤집기 (업사이드 다운, v04 `00:22.000`~`00:25.333`)**
   - **이유**: 댄스·인물 챌린지에서는 호기심을 끌지만, 음식점 메뉴·병원 시설·아파트 매물·차량 사진이 거꾸로 나오면 고객이 1~2초 안에 **무엇을 파는지 인지하지 못해 이탈**합니다. 특히 음식을 뒤집어 보여주면 식욕을 떨어뜨립니다.
2. **초록색 코드 비 오버레이 (코딩 매트릭스, v03 `00:13.667`~`00:15.667`)**
   - **이유**: 토킹헤드에서 "머리가 복잡하다"는 개그성 연출에는 어울리지만, 자영업 매장 사진(음식·피부 시술·카페 공간·의류) 위에 초록색 글자가 덮이면 **사진의 본래 색감과 청결함·고급스러움을 심하게 훼손**합니다.
3. **0.33초 단위 네온 하트·별 스티커 점멸 및 3D 요동 (v08 `00:02.333`~`00:07.000`, `00:17.667`~`00:23.333`)**
   - **이유**: 과한 네온 핑크 하트·구름 스티커와 검은 여백 속 거친 3D 흔들림은 자동차 영업·부동산·병원·학원·인테리어 같은 **신뢰와 전문성이 생명인 업종을 촌스럽거나 가벼워 보이게** 만듭니다.
4. **0.6~0.75초 초고속 비트 컷 연속 (v07 `00:07.667`~`00:30.667`, v10 `00:05.333`~`00:12.667`)**
   - **이유**: 사장님이 가진 사진은 보통 4~10장뿐인데 0.7초마다 컷을 넘기면 영상이 너무 빨리 끝나거나 같은 사진을 무리하게 재사용해야 합니다. 또한 **매장 위치, 가격, 시술 디테일, 자막을 시청자가 읽을 시간 자체가 부족**해집니다.
5. **정밀 인물 누끼에 의존한 배경 분리/텍스트 뒤 배치 (v04 `00:03.333`~`00:25.333`, v08 `00:00.000`~`00:07.000`, v10 `00:04.333`)**
   - **이유**: 단일 인물 중심 릴스에서는 자연스럽지만, 사장님 홍보 사진은 인물 외에 **음식 접시, 자동차, 넓은 거실 인테리어, 여러 학생/손님**이 섞여 있는 경우가 많습니다. 자동 누끼 경계가 지저분하게 뜯기거나, 자막이 피사체 뒤로 가려져 **핵심 홍보 문구 가독성이 떨어질 위험**이 큽니다.
6. **15초 이상 노컷 롱테이크 + 극저채도 빈티지 필터 + 초소형 이모지 자막 (v09 전체)**
   - **이유**: 아는 사람끼리의 감성 브이로그가 아닌 **불특정 다수 대상 홍보 광고**에서는 첫 2~3초 안에 시각 변화가 없으면 바로 스크롤됩니다. 또한 물 빠진 저채도 보정은 음식점·카페·쇼핑몰 상품의 신선함과 발색을 죽여 구매 전환에 불리합니다.
