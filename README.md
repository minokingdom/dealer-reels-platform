# AutoReels 50K — 자동차 딜러 주간 숏폼/릴스 임시서버 검수 & 인스타 자동 발행 플랫폼

주 1회 5만 원에 자동차 딜러들의 프로모션 릴스를 제작·배포하기 위해 설계된 **원소스 멀티유즈(공통 본편 + 딜러별 마지막 엔딩 명함 자동 합성) + 임시서버 승인제 인스타그램 자동 업로드 플랫폼**입니다.

## 주요 기능

1. **원소스 멀티유즈 영상 자동 합성 (`ffmpeg-compositor.js` & Web Canvas 렌더러)**
   - **0~8초 (공통 프로모션 본편)**: 매주 제작하는 차량 프로모션 영상 하단에 각 딜러의 `[소속 | 이름 직함 | 연락처]` 워터마크 바를 상시 노출합니다.
   - **8~12초 (딜러별 신상정보 엔딩카드)**: 영상 마지막 4초에 딜러마다 다른 이름, 소속 전시장, 직통 연락처, 개인 출고 혜택이 담긴 명함 카드를 자동으로 이어붙입니다.
2. **임시서버 모바일 검수 & 원클릭 승인 (`public/index.html`, `server.js`)**
   - 딜러에게 카카오톡 알림톡으로 전용 검수 링크(`https://staging.autoreels.kr/v/{token}`)를 발송합니다.
   - 딜러가 본인 신상정보가 합성된 최종 영상과 인스타그램 본문(캡션)을 확인하고 **[승인 완료]**를 누르면 즉시 인스타그램 업로드가 실행됩니다.
3. **인스타그램 계정 보안 보관 & 자동 게시 (`instagram-api.js`)**
   - 딜러의 인스타그램 아이디/패스워드 수취 시 `AES-256-GCM` 암호화 볼트로 안전하게 저장하거나, Meta 공식 `Instagram Graph API`(`REELS` 컨테이너 발행)를 통해 계정 차단 없이 자동 업로드합니다.

## 프로젝트 구조

- `public/index.html` — 별도 서버 설치 없이 브라우저에서 바로 열리는 올인원 인터랙티브 스튜디오 (실시간 9:16 릴스 합성 미리보기 & `.webm` 영상 추출 지원)
- `server.js` — 임시서버 API 및 승인 웹훅 처리 Node.js 서버
- `ffmpeg-compositor.js` — 마스터 영상 + 딜러 엔딩 명함 자동 결합 FFmpeg 파이프라인 모듈
- `instagram-api.js` — 딜러 계정 AES-256 암호화 보관 및 Instagram Graph API 릴스 자동 업로드 모듈
